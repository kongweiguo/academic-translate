# 使用指南

[项目首页](../README.md) · [技能入口](../SKILL.md) · [翻译工作流](../references/workflow.md)

## 开始前

先按[安装、更新与跨宿主使用](../README.md#安装更新与跨宿主使用)保存完整技能目录。推荐通用位置 `~/.agents/skills/academic-translate/`，也可自选目录；安装不依赖特定 agent 或 LLM。仅历史重建前的旧 Git 克隆需要保留本地修改后重新克隆 `master`；已采用新历史的克隆按 README 快进更新，不必再次克隆。

提供可读取的 PDF、在线正文或原始平台链接。在线附件应同时提供承载页面或文件夹线索；临时下载地址通常不足以确认输出父级。本地源需要可读取，译文目标需要可写；普通翻译不要求源文件改名权限。

通用目录不保证所有宿主自动发现。无法自动发现时，让具备本地文件读取能力的宿主读取实际路径中的 `SKILL.md`，再按入口读取 `references/workflow.md`：

```text
请读取 ~/.agents/skills/academic-translate/SKILL.md 及本次任务需要的参考章节，
完整翻译 /path/to/paper.pdf，生成本地中英对照 Markdown。
```

Windows 使用实际路径，例如 `C:\Users\<用户名>\.agents\skills\academic-translate\SKILL.md`；自选目录同样替换为实际路径。无本地文件访问能力的聊天环境，可直接提供 SKILL、所需引用文档和论文内容，交付形式依其可用能力而定。`$academic-translate` 仅是部分宿主的可选语法，不用安装校验器或执行技能附带程序，本技能没有这些依赖。

## 使用场景

### 本地完整翻译

```text
使用 academic-translate 完整翻译〈论文路径.pdf〉，按默认中英逐段对照格式保存本地。
```

原文件名称与内容保持不变，新成果按当前目录取号在原父目录创建 `[P001][翻译]B/[P001][翻译]B.md`，同时保存 `images/` 与原有 `translation-state.json` 翻译进度，不新增编号状态文件。这里 `P001` 仅示意现场取得或核实复用的编号；`B` 是不含已核实编号、类型标记和真实扩展名的基本名，可为六段书目名或普通源基本名。译文开头以相对链接访问实际原 PDF，并提供“原文｜翻译｜精读”导航。源旁边无法写入时需使用用户指定的可写位置。

读取实际安装的 `academic-rename/SKILL.md` 及其 `references/naming.md` 中[“共享编号与目录取号”](https://github.com/kongweiguo/academic-rename/blob/master/references/naming.md#共享编号与目录取号)和“类型前缀与基本名”，按唯一规范完整列出实际源父目录或在线父容器的直接子项，不递归全库；用户另定输出位置时按该规则确认范围。需要新号时取当前最大可识别前置编号加一，没有则从 `P001` 开始。例如其他论文最大编号为 `P012` 时，`paper.pdf` 的新译文用 `[P013][翻译]paper/[P013][翻译]paper.md`，原件不改名。不启动 CCF、书目规范化或源改名；编号提取、取号、冲突和组合命名均不由翻译技能另定。

同源同版本的原文、译文或精读已有编号时先核实后复用；源未编号也可从已有成果识别，重复执行不重新编号。同批同篇共享内存交接编号，写入前重读目录；结果未知先读真实资源，不立即另领号。不新增编号账本、计数器或占号文件，现有进度仅保存实际名称、位置和编号线索，不能作为发号台账。名称相似或同哈希不自动合并，新版本不关联旧成果，必要时取新号；跨目录同号以实际范围路径/容器 ID 和真实资源 ID 区分，不承诺全局唯一或删除后永不复用。缺少规则、完整目录列举权限或可核实基本名时继续内容并标明命名待处理，可续现有成果或用用户明确名称，不猜编号。

### 飞书或 Notion 在线翻译

```text
使用 academic-translate，完整翻译〈原文链接〉，在原文对应层级创建译文。
```

原生文档按现场取号或核实复用的编号沿实际父级创建同级 `[P001][翻译]B`；飞书知识库沿节点父级定位。附件则在其实际承载容器内创建成果，例如 Notion 附件所在页面内的新译文子页面。不会因为附件翻译而改承载页标题，也不会把下载缓存当成本地来源。

在线有原始 PDF 时插入平台托管的真实原生附件；只有正文时提供源链接。原始附件上传受阻须保留明确未完成状态。

### 指定目的地或排版

```text
使用 academic-translate 翻译〈源路径或链接〉，输出到〈目标平台与父级链接〉。
参考〈参考文档〉的排版，保留原文与译文逐段对应。
```

明确目的地优先，跨平台需要相应读取及写入能力。参考文档只提供样式，不能替代当前论文的题名、作者、内容或处理范围。本地来源明确输出在线时不额外创建本地译文目录。

### 更新或续写

```text
使用 academic-translate，继续〈已有译文路径或链接〉。
原文为〈源路径或链接〉。保留我已改过的部分，补齐剩余章节并核对公式。
```

先回读当前目录、源身份、状态和实际正文，按已有路径或 ID 继续，包括旧 `N_翻译/N_翻译.md` 和 `[翻译]B/[翻译]B.md`。旧 `translation-state.json` 和 `rename-log.json` 保留；不要求发生过改名，不因取号规则变化迁移或另建目录。同名无关成果不能覆盖，源已修订须先核实版本，不把旧成果当作新版成果。只有明确要求调整已有成果名称时，才由 rename 规划目录与正文的改名及恢复记录，翻译技能负责可验证的引用、导航与进度修复并保留用户修改。

续作先核对已有导航，只更新可确认属于本任务且未被用户改动的部分，不重复添加。相关精读必须实际读取确认同源同版本才关联；在任务授权范围内同步其译文链接，不能写入或用户已改动时记录待同步。未生成、未找到、待核实分别标明，不填写候选 URL，不批量修改真实原文。

### 明确命名或整套处理

```text
使用 academic-rename 先规范〈论文路径或链接〉的名称，然后用 academic-translate 完整翻译。
```

```text
使用 academic-suite，完成〈论文路径或链接〉的命名、完整翻译和精读。
```

共享编号、规范命名及其预览、恢复均由 `academic-rename` 负责。组合任务传递编号、`[翻译]` 标签、真实扩展名与完整目标路径约束，分别接收改名后回读的实际源名及已核实 `B`、实际编号范围路径/容器 ID 和同批共享编号；写入前仍回读目录，源引用使用实际名称，成果使用已核实组合名，不叠加源标签。Suite 还协调独立精读成果及人读论文索引，索引仅展示，不参与取号。只要译文时直接调用 translate，不必绕经套件，也不自动创建精读或论文索引。

撤销改名时先由 rename 恢复源名；本技能只对可验证属于本任务且未被用户修改的链接、导航与状态作必要修复，保留译文和图片。改名或恢复后重新核验本地相对链接与在线稳定 URL，将实际位置、关联资源和导航同步状态交回套件。

## 交付与检查

依 [SKILL 验收要求](../SKILL.md#通过-skill-验收) 加载工作流，对照原文检查全文覆盖、段落对应、数字与术语、图表题注、公式渲染、信息卡及实际源访问。新成果编号位于最前、类型紧随且无重复，已现场回读目录或核实已有编号，已有成果保持原位续作；长度与冲突按 rename 唯一规则检查，计入编号、类型与完整路径。导航只能指向已核实同源同版本的实际资源，缺失及待同步状态明确。检查由 SKILL 指令组织，不运行外部校验脚本或安装依赖。

全文所有数学表达式强制使用 LaTeX，尤其是中英段落中的变量、上下标和短公式。行内用 `$...$`，独立公式用 `$$...$$`，在线使用 LaTeX 数学节点；表格、题注、脚注、附录及图中的公式同样检查，图中公式须另附转写。逐段检查遗漏与实际显示，不能只查有编号的公式，不能用普通文本、反引号或图片替代。真实代码和命令保持语法；无法转写或验证的项目如实列为未完成/未验证。

交付应包含实际源与译文位置、覆盖范围、进度位置、实际编号与范围路径/容器 ID、`B`、关联资源及真实 ID、导航同步状态和未完成事项。在线附件须实际打开或下载核验，本地源与图片相对链接须可访问；缺少查看能力的项目明确标为未验证。将实际链接和缺失状态交 suite 更新展示索引，单独翻译不另建索引，也不保存新增发号状态。

| 情况 | 处理 |
| --- | --- |
| 技能未发现 | 检查目录层级和当前宿主发现方式，也可显式读取 SKILL |
| 同名译文已存在 | 先核实来源身份；属于本任务则续作，否则使用用户指定的其他目标 |
| 源文件只读 | 读取原文并向已授权可写位置输出，普通翻译不改源名 |
| 在线父级不明或不可写 | 继续可独立完成的整理，说明需补充的实际位置，不擅自换父级 |
| PDF 或图片链接失效 | 核对实际相对层级与 URI 编码；源名恢复后的引用按授权范围修复 |
| 原始附件上传失败 | 使用当前支持的方式处理，仍失败则说明，不静默改为普通链接 |
| 公式不显示 | 用已有查看能力检查，尝试等价的兼容 LaTeX；保留源码并记录未完成/未验证，截图不能代替公式通过验收 |
| 双栏或 OCR 错误 | 对照原页纠正顺序和识别，无法确认处标记 |
| 名称过长或目标占用 | 不暗中改源名；采用用户指定输出或显式交由 rename 规范命名 |
| 编号或基本名无法核实、规则不可用或目录列举不全 | 继续可独立完成的翻译内容，可续现有成果、标明命名待处理或使用用户明确名称；不猜编号、剥除或叠加标签 |
| 精读缺失或身份不明 | 标明未生成、未找到或待核实，不伪造链接或自动新建精读 |
| 精读不可写或导航被用户修改 | 保留原状并记待同步，交接已核实链接及所需变更 |
| 切换 agent 或设备 | 一并提供原文、已有成果及持久记录，重新核对身份后继续 |
