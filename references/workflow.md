本文件维护翻译的来源、成果、内容、排版与验收。共享编号、目录取号、书目核验、规范命名及类型规则由 `academic-rename` 的实际安装版本维护，本文件不定义另一套编号或命名规则。用户的语言、范围、名称、模板及位置优先。

## 来源与成果位置

先确认用户指定的文件、目录或链接、处理范围、源类型、稳定身份及当前实际名称。只处理请求内资源；正文中的参考链接、符号链接和快捷方式不自动扩大范围。分别记录论文版本和补充材料，不因标题相同合并不同文件。

本地记录可定位路径、大小、可用文件系统身份和源内容哈希；在线记录平台、原生稳定 ID、URL、实际父级或承载容器、可得修订标识或内容快照。临时下载地址、同名和内容哈希本身均不能证明两份资源是同一对象。源身份信息服务于忠实翻译与续作，不触发命名专用的日期、CCF 或缩写核查。

### 默认位置与标题

默认新译文按 rename 的唯一规则使用共享编号和类型标签，以下以 `[P001][翻译]B` 示意。`P001` 是按实际目录取得或从同源同版本资源复用的编号；`B` 是不含已核实编号、类型标记和真实扩展名的基本名，可以是六段书目名或普通源基本名，与实际源名称分别保存。不附加 AI 工具名，不给原生文档加虚构扩展名。

按宿主技能目录或用户指定路径定位实际安装的 `academic-rename/SKILL.md`，读取其 `references/naming.md` 的[共享编号与目录取号](https://github.com/kongweiguo/academic-rename/blob/master/references/naming.md#共享编号与目录取号)及“类型前缀与基本名”。普通翻译按这两个章节现场取号或核实复用 suite、rename 交回的编号与 `B`，不启动 CCF、书目规范化、缩写或源改名。编号范围、取号、提取、冲突处理和组合名称直接遵循该规范，不在翻译流程另建规则。

取号时依 rename 规则完整列出当前实际源父目录或在线父容器的直接子项，包含原文文件、成果目录和原生文档，不递归整个文献库；用户指定其他输出位置时先按该规则确认实际编号范围。已有同源同版本的已编号原文、译文或精读优先核实后复用；源未编号也可从已有成果识别。需要新号时采用当前目录最大可识别前置编号加一，无编号时从 `P001` 开始。名称相似、题名相同或哈希相同不自动合并资源；新版本不关联旧成果，必要时现场取新号。普通源基本名沿用并不表示书目已核验。

同批同篇共享内存交接的编号，写入前重新读取目录；创建或写入结果未知时先读取真实资源，不能立即另取一个号。不新增编号账本、计数器、占号文件或永久登记，论文索引也不参与取号。不承诺跨目录全局唯一或删除后永不复用；跨目录同号以实际范围路径/容器 ID 和真实资源 ID 区分。

缺少规则、完整列举目录的权限或可核实基本名时，不猜新号；继续可独立完成的翻译内容并明确编号或命名待处理，可续作已有成果或按用户明确指定的名称保存。不将姓名、题名中的相似文字当作编号或类型剥除，不将未核实的候选编号写成实际名称。

用户明确只规范新成果名称而保留源名时，可使用 rename 交回的已核验成果基本名；源引用和附件始终使用真实源名及身份。此时源名与成果基本名不同是明确要求的结果，不能把命名预览或待核实候选当作最终成果名称。

| 来源 | 默认位置 |
| --- | --- |
| 本地 PDF | 原父目录中的 `[P001][翻译]B/` |
| 飞书/Lark 文件或正文 | 实际父目录内；知识库按原文节点的父级创建同级成果 |
| Notion 原生页面 | 原页面实际父级内，与原页面同级；数据库等特殊父级先核实支持的创建方式 |
| 在线附件 | 在附件实际承载页面、文件夹或知识库容器内创建成果，不把附件当作独立父页面，也不改承载页标题 |
| 明确指定输出位置或已有译文 | 按指定目标执行 |
| 其他来源、只有临时本地附件 | 使用已有目的偏好；仍缺少持久位置时只补充必要信息，并继续原文整理 |

在线来源下载到本地只是缓存，不因此切换默认目的地。无法定位或写入在线同级位置时说明受阻，不能悄悄换到根目录或把本地草稿当作在线交付。用户明确指定本地来源输出在线时，只生成指定在线成果，不额外要求本地目录。

### 输出规划与占用

先读当前目录、已有成果与进度，再规划新输出。现有翻译进度保存源身份与版本、实际源名称与位置、实际范围路径/容器 ID、已核实基本名 `B` 及依据、目标父级、译文标题或路径、创建状态和用户偏好；实际名称中的编号可作定位线索，不能把进度当作发号台账。编号或命名未定时如实记录，不将猜测写作编号或基本名。

- 同名目录或页面不证明可续作。只有源身份、已记录成果路径或 ID、创建记录和当前内容相符，才更新已有成果；保留用户修改。
- 新输出前检查目录、Markdown、图片及在线同级目标；已有无关或归属不明成果不覆盖。用户未给出替代位置时说明具体占用并请求必要的新位置或名称，其他独立任务继续。
- 默认沿用基本名不会自动缩写长标题或清理成另一套书目名。可保存性和长度预算按 rename 的“名称与位置冲突”规则检查，计入实际编号、类型标签、真实扩展名及目录和正文的完整路径，本技能不另设长度阈值。目标平台无法容纳名称时，采用用户指定的可用名称或位置；需要规范命名时交由 rename 统一规划，不暗中改源名。
- 组合命名任务把 `[P001][翻译]B/[P001][翻译]B.md` 等实际目标结构和平台限制交给 rename 一并规划。只有命名预览时不创建正式译文。
- 明确指定已有译文时沿用其记录路径和 ID，不因源名或默认规则变化另建一份，也不叠加类型标签或旧后缀。

## 本地翻译

确认来源可读、目的位置持久且可写。源文件只需读取，普通翻译不要求源改名权限。建立内容清单后直接创建或续写译文，不以 rename 日志存在为条件。

### 目录与链接

默认结构如下；`实际源文件名.pdf` 是实际源文件的示意占位，可能含已确认的 `[原文]` 或 `[P001][原文]`；真实名称、扩展名及大小写保持原样。`P001` 仅示意现场取得或核实复用的编号，`B` 只用于成果名称，不新增编号状态文件：

```text
parent/
├── 实际源文件名.pdf
└── [P001][翻译]B/
    ├── [P001][翻译]B.md
    ├── images/
    │   ├── fig-01-p003.png
    │   ├── table-01-p005.png
    │   └── equation-07-p006.png  # 可选原式对照，不能替代 LaTeX 转写
    └── translation-state.json
```

1. 创建前在任务工作区保存源身份、输出计划与本批创建进度；逐项记录实际创建结果。目录被其他操作抢先创建时先核实归属，不直接复用。
2. 正文写入 UTF-8 Markdown。全部图表、续页和用于核对原式的可选裁剪放入 `images/`，使用能对应原图号和页码的稳定名称，不覆盖另一张已引用图片；公式裁剪仅作对照，正文仍必须有可编辑 LaTeX。
3. 持久进度放入 `translation-state.json`；创建中断时保留工作区记录，恢复后核对实际目录再补缺失步骤。普通翻译不创建空的改名日志。
4. 本地源 PDF 留在原位置，不为模拟在线附件而搬动、复制或重新导出。用户指定其他输出根目录时按实际位置计算源引用。
5. 源链接相对于 Markdown 所在目录按实际源路径计算，例如 `../实际源文件名.pdf`；不能用 `B.pdf` 代替带有前缀或其他名称的真实源文件。显示实际文件名；图像形如 `images/fig-01-p003.png`。路径按段使用 UTF-8 URI 编码，编码空格、中文、`#`、`%`、括号等，保留路径分隔及相对层级；显示文字中的 Markdown 特殊字符也需转义。交付正文不依赖本机绝对路径或临时缓存。

显式命名任务的日志仍由 rename 保存和解释。若旧输出中已有 `rename-log.json`，保留并在翻译进度中引用，不移除、不伪造或重写其改名成功记录。

## 在线翻译

先确认来源实际归属和目标父级，核实读取、创建或编辑、上传原始附件及查看能力。平台名称不是授权，临时签名 URL 和 CDN 域名也不证明父级位置。通过当前已连接能力处理；相关平台技能可用时读取其说明，不强制安装特定插件。

普通翻译保留源标题，按现场取号或核实复用的编号创建 `[P001][翻译]B`；指定已有译文时直接更新该资源。记录源与译文稳定 ID、URL、实际父级和可获修订标识。套件或 rename 传来的实际源名须回读确认，写入前重新读取编号范围的当前子项，成果使用同批交接的编号与已核实 `B`，不能重复带入源的编号或 `[原文]` 标签，也不能用候选名或 `B` 替代实际附件名称。源只有读取权不阻止向已授权位置写译文。

长文分段写入；每段之后记录实际写入块或章节。写入超时或返回结果不明时先回读再续写，避免重复块或重复文档；暂时限流及网络错误最多重试三次，权限或类型限制应直接说明，不换身份绕过。

### 原始文件附件

- 有原始 PDF 或补充文件时，将原始字节上传或通过平台受支持方式复制为目的平台托管文件，在开头信息卡底部插入原生附件或 PDF 块；无法嵌套则紧接卡片下方、范围段之前。
- 使用源实际当前名称。套件已改名时用核实的新名，未改名时用原名；截图合集、重导 PDF 或转换文档不能冒充原始文件。
- 附件应绑定真实内容和平台文件标识。普通链接、书签、图标、文件名文字及仅依赖外部地址的预览不能替代原生附件；源网页链接只作补充。
- 多份文件逐项标注用途及版本关系，开头只保留一套附件列表。完成后实际打开或下载绑定最终文档的附件，核对名称、内容和完整性。
- 上传受限时尝试当前环境已支持的方式；仍失败则列为未完成，不静默换成链接。只有在线正文、没有原始 PDF 时不自行生成并称为原始 PDF。

## 进度与兼容续作

沿用可直接读取的翻译进度保存：源稳定身份与实际名称及位置、版本、哈希或修订、已核实 `B` 及依据、成果路径或 ID、创建事实、任务范围、偏好、术语、已完成章节与物理页码、图片来源页及裁剪区域、待处理和未验证项。编号范围的实际路径/容器 ID 和已落在实际名称中的编号可作定位线索，不新增编号状态记录，也不能将现有进度或索引当作发号台账；继续前仍回读目录。各关联资源保存实际名称、路径/稳定 URL、资源 ID、同源同版本依据、可访问状态、导航位置/前后快照及同步状态；未生成、未找到、待核实、待同步均明确区分，不用猜测值填空。数学记录区分 LaTeX 转写完成与渲染核验完成，标出遗漏、不可辨认或未验证表达式的段落/页码位置。状态按实际区分 `in_progress` 与 `complete`；源全文不复制进状态记录。在线记录保存于任务工作区，不自动上传日志到源平台。

已有 `translation-state.json` 与旧 `schema_version: 2` 的 `rename-log.json` 可作为续作证据。保留原 `resource_id`、历史路径、缩写映射和成功事实；旧字段 `renamed_path` 等按历史事实读取，普通新任务不需要改名状态为 `verified` 才能翻译。

先核对当前目录、源、日志及实际成果。以记录的输出路径或原生成果 ID 继续已有成果，包括旧 `N_翻译/N_翻译.md` 和 `[翻译]B/[翻译]B.md`；不因编号或类型规则调整重算名称、迁移目录或建立第二份。只有计划不能证明目录已由本任务创建；同名、损坏日志或来源不明资产不能作为覆盖依据。进度与实际内容不同，以回读修正完成范围，保留用户修改，只补缺失内容。

只有用户明确要求调整已有成果名称时，才由 rename 按其唯一规范规划目录、正文文件、在线标题及恢复记录；本技能在实际改名回读后，只修复可验证归属且未被用户改动的关联引用、导航和进度。重新打开本地相对链接及在线稳定 URL，核实实际源、译文和精读；候选路径不能写入导航。将修复范围、前后快照及回读结果交回同批迁移日志，并将实际位置与状态交 suite 更新展示索引，按唯一规范维护恢复依据。不能安全修复的项目列明待同步，不覆盖用户编辑，也不删除重建。

换会话、agent 或设备后，重新解析当前路径并核对身份；聊天记忆、工具调用 ID、旧机器绝对路径和临时 URL 不能代替持久记录。哈希或修订变化时先判定是否新版本，不能自动把旧译文套到新原文。

恢复源名由 `academic-rename` 执行。本技能接收恢复后的实际位置，对可证实属于该任务且未被用户改动的源链接和对应状态做最小修正；不能安全修复时报告失效引用及真实源位置。默认保留译文目录、标题、图片和正文，不通过删除重建完成恢复。

## 文档互联

完整译文开头添加“原文｜翻译｜精读”导航，保留原有源链接、信息卡和原始附件。每一项使用实际读取并核实的本地路径或在线稳定 URL；当前位置可写“翻译：当前文档”。未生成的阶段写“未生成”，已查找但没有找到写“未找到”，身份或版本尚不确定写“待核实”，均不附候选链接。

只关联已读取确认与本译文同源、同版本的精读，结合实际范围路径/容器 ID、源与成果真实资源 ID、版本和实际内容核对；同编号只是定位线索，跨目录同号不表示同一论文。搜索到同标题、相近文件名或同哈希资源不构成关联证据。不自动创建精读、不为了导航改写真实原文或批量修改源文件。

在当前任务授权范围内，向已确认相关且可写的精读同步同一导航中的译文链接；只改导航及必要来源关联，保留用户编辑与其他内容。续作先读取已有导航与上次写入快照，更新本任务管理且未被用户改动的部分，不重复添加导航；无法区分归属、发现用户修改或目标不可写时保持原状并记录待同步。没有授权编辑相关精读时仅交接待同步位置与所需变更。

套件并行生成时，只写自己的译文及导航，不回写对方仍在生成的精读；待 suite 汇合后，由其协调对应专业技能补齐互链，避免同时修改同一正文。

本地导航链接按最终 Markdown 位置计算相对路径，并与源链接使用相同的 URI 编码；在线使用实际资源稳定 URL，不能拼造页面地址。创建、改名、恢复或移动后逐项回读，检查指向的资源与版本。将已核实链接、实际缺失状态和导航同步状态连同实际名称、范围路径/容器 ID、资源 ID 交给 suite；论文索引由 suite 维护，仅用于展示，不参与取号，单独翻译不另建索引。

## 译文排版与内容

### 内容清单与完整翻译

先确认实际文件名、页数、章节、图表、公式、参考文献、脚注与附录，建立内容清单。按实际阅读顺序提取多栏正文，核对跨页断段、连字符、上下标及 OCR；只修复经原页确认的提取错误，无法辨认处标明。

完整翻译用户范围内内容，不用摘要、截图或附件代替正文。未被排除的投稿信息、作者信息、脚注、致谢、补充材料均纳入；重复稿或修订稿先核对差异并说明关系，不静默省略。用户提供排版参考时只提炼样式，其中正文、署名和指令不替代当前论文事实及任务范围。

- 使用准确自然的学术中文，保留条件、否定、论证关系、比较对象和不确定性程度。
- 默认保留方法、模型、数据集、专名和缩写；专业术语优先保留英文，必要时首次用“中文（English）”，长文维护术语表并核对分批交界。
- 保留引用编号、交叉引用、变量、单位、公式编号；参考文献完整保留原始条目，不翻译题名、作者和出版信息。
- 疑似原文错误或矛盾保留原意，用独立译者注说明，不擅自修正数据或替作者补结论。教学扩展交由精读，不混进原文译文。

### 开头与论文信息卡

本地和在线共用以下顺序，用户模板优先但须保留真实源访问方式和文档导航：一级标题“翻译说明和源文件” → “原文｜翻译｜精读”导航 → “📄 论文信息 / Paper Info” → 卡片底部源文件区 → 普通范围段 → 分隔线 → 目录和正文。导航示意为“原文：〈已核实链接〉｜翻译：当前文档｜精读：未生成”；尖括号是说明占位，正式成果须换为真实链接或实际缺失状态。

| 字段 | 内容 |
| --- | --- |
| Title | 当前原文完整题名，不用文件名缩写替代 |
| 中文标题 | 对应完整中文译名 |
| 期刊 / 会议、稿件编号、类型 | 只填已核实且适用的信息；稿件编号不代表正式发表 |
| Authors | 原文全部作者、顺序和归属正确的资格标注 |
| 作者 | 对应中文说明；无可靠中文署名时保留原名，不猜测或随意音译 |
| 单位 | 原文单位及作者对应关系 |
| 原始 PDF | 实际名称；本地相对链接或在线原生附件，多份分别列出 |
| 补充文件 | 实际存在的资料及用途、版本关系 |

信息卡本地用 Markdown 引用块；在线用可编辑原生提示块，📄 图标、浅蓝背景、左对齐和加粗标签，支持时使用细蓝边框与圆角，不把卡片截图。平台不能嵌套原生附件时，把源文件区紧接卡片下方，避免在卡片前再重复文件列表。没有原始 PDF 的正文来源提供真实源链接。

范围段只写实际核实的信息：物理页序、必要时的印刷页码、章节、用户限制、附录及版本关系。未知字段省略；不照搬示例中的页码或“某版本不重复翻译”。范围说明必须与最终正文、附件和附录一致。

### 正文、目录与文末

保留原始章节编号与层级，目录和章节标题中英对照。按语义段落一一排列原文和译文，合并分栏或分页造成的断段，列表逐项对应，不把整节合成一个大段。默认英文在前用 **[EN]**，中文紧随其后用引用块和 **[ZH]**。其他源语言遵循用户设置，不能把非英文原文误标为英文。

参考文献单列章节并完整保留原文。投稿材料、重复版本和修订稿可由附录承接，说明来源关系而不省略。文末按需列术语处理、原文疑点、公式待转写/待验证项及实际 AI 工具署名；型号未知时省略，不照搬其他译文署名。

### 图表与题注

- 从原文件裁取图表，保留全部子图、图例、坐标轴、表注和完整原始题注；不翻译图内文字、不重绘或改数据，中文题注另放下方。
- 跨页图表保留全部续页和说明，不能合理合并时顺序分张；放在对应讨论附近，保持引用关系。
- 使用足够清晰的原尺寸，优先原始 PNG，避免反复压缩；导入明显降质时改用原始图片上传。
- 图内公式随原图保留，并在图旁提供对应的可编辑 LaTeX 转写，注明图号和对应位置，不能只留在图片中。本地图表、续页和原式对照裁剪都放在译文 `images/`，不依赖临时路径或外部图床。

### 公式

全文所有数学表达式必须使用可编辑 LaTeX，不能只转换独立编号公式。英文原文与中文译文两侧的每个段落、标题、列表、表格单元格、题注、脚注和附录均适用，包括句中的单变量、希腊字母、上下标、向量/矩阵、集合与概率、取值范围、张量尺寸、复杂度、损失和指标定义；原文中未编号的短表达式不能遗漏。普通叙述数字、年份、文献编号无需一律转成公式。

本地 Markdown 行内用 `$...$`，独立成行用 `$$...$$`。例如正文写成“输入为 $\mathbf{x} \in \mathbb{R}^{H \times W \times C}$，扰动满足 $\lVert \boldsymbol{\delta} \rVert_\infty \leq \varepsilon$”；不能把相同数学内容写成普通字符或内联代码。在线使用以 LaTeX 表达式为内容的原生行内/块级数学节点，不能把含美元符的普通文本误当作已创建的数学节点。保留源中的行内/独立公式语义位置，不能为规避行内排版而全部挪到段尾。

公式不能用纯文本近似、Unicode 上下标、反引号、普通代码围栏或图片替代。真实可执行代码、命令、路径、URL 和配置键使用原有代码语法，不往实际代码中插入数学分隔符；围绕这些内容的数学解释仍必须用 LaTeX。原图及原式截图可以作为对照证据，但图中公式也须另有 LaTeX 转写。

逐式核对变量、上下标、希腊字母、粗体、向量、矩阵、分段、运算符和编号；不能将 Unicode 外观相似字符当作 LaTeX 转写，也不能用 `$...$` 包住未经转换的近似文本就算完成。编号命令不支持时在邻近文本保留编号。平台不支持某命令时采用数学含义等价的兼容 LaTeX 写法，不简化或改变数学含义。

无法准确辨认或转写时不猜公式，记录原文位置和待补项。无法创建数学节点或查看渲染时，保留已核对的 LaTeX 源码并明确数学排版/渲染未完成或未验证；不能改用普通文本或截图后标记通过，也不擅自更换交付平台。写入后逐段查看行内与独立公式的实际显示，与原文对照；源码存在不表示渲染正确。继续能够独立完成的内容工作，不安装校验脚本或依赖来代替技能验收。

## 交付核验

执行者重新加载 SKILL 的验收要求，按本节使用原文、实际成果和进度做阅读与回读对照。核验由技能指令组织，不使用外部校验脚本或新增程序依赖。未完成或未验证事项清空后才能标 `complete`；否则明确保持处理中。

- **源与成果身份**：实际源名、路径或 ID、版本、父级、译文路径及附件名称一致；普通翻译未改源名，按 rename 规则完整回读当前编号范围的直接子项后取号，或核实复用同源同版本原文/成果编号，未重编已有成果。新译文编号在最前、`[翻译]` 紧随且无叠加，长度及占用按 rename 的唯一规范检查；编号或基本名未核实时不得声称命名完成。未新增编号账本或用进度、索引发号；源内容与读取快照相符，不能拿候选名当成功结果。
- **内容覆盖**：逐项核对正文、脚注、投稿信息、作者、致谢、图表、公式、参考文献和附录；无漏译、重译、截断或未完成占位，特别检查跨页、多栏及分批交界。
- **忠实与排版**：数字、单位、术语、引用、EN/ZH 对应准确；信息卡、源文件区及范围顺序正确，实际范围与声明一致。
- **源访问**：本地实际打开相对链接指向的原 PDF，核对来源身份；在线存在原始文件时打开或下载最终文档绑定的原生附件，检查真实名称、内容与完整性。仅在线正文来源则打开真实源链接，核对所引用的原文和版本。图标和链接文字本身不是验证。
- **文档导航**：开头有且只有一套所需导航，所有链接指向实际读取确认的同源同版本资源；缺失阶段状态准确，无候选 URL。核查现有精读的导航同步结果，未授权、不可写、归属不明或用户修改处记录待同步；改名后的相对路径和稳定 URL 已回读，未批量修改原文，未自动新建精读或索引。
- **图片与公式**：本地打开全部图片引用，确认真实路径位于当前译文 `images/` 内；在线查看最终文档中的实际图片及平台托管资源。核对宽图、复杂表格、原始题注与中文题注；按英文/中文每个段落逐项检查行内变量、上下标、短表达式和独立公式，再检查表格、题注、脚注、附录及图中公式的 LaTeX 转写。逐式查看实际数学显示，不能仅查编号公式、美元符或图片是否存在。纯文本/反引号/截图替代公式、错误数学节点、缺失转写均为未完成；没有查看能力时列明未验证项。
- **续作**：回读实际成果与记录，确认无重复成果，用户修改保留，历史改名日志及已有成果位置未被默认流程重置。

交付实际源文件及译文访问位置、翻译覆盖范围、图片位置、进度记录、实际编号与范围路径/容器 ID、`B`、各关联资源及真实 ID、导航同步状态和剩余问题；编号缺失时如实注明。套件任务将实际名称、位置、创建状态和链接核验结果交 suite 维护人读索引，不新增发号台账。组合命名任务引用 rename 的结果，不重新输出另一套判级结论。HTML 或 PDF 预览不能替代所要求的 Markdown。分享本地完整成果时同时保留原 PDF 与译文目录的相对层级，确保链接可用。文档审查、实际平台查看与实验运行分别说明，不把部分成果称为完整交付。
